# Contributing to DeforaSec

Thank you for your interest in contributing to DeforaSec's mission of advancing security research and open-source tooling.

## How to Contribute

### Research Submissions
- Use the template at `research/RESEARCH_TEMPLATE.md` for all security write-ups.
- Ensure all findings are responsibly disclosed before publishing.
- Include clear reproduction steps and remediation recommendations.

### Tooling
- Submit security scripts and utilities under `/tools`.
- Each tool should include a brief README documenting usage, dependencies, and purpose.
- Follow security best practices — no hardcoded credentials or unsafe defaults.

### Open-Source Contributions
- Document your contributions to external projects in `/contributions`.
- Follow the table format used in `OSS_CONTRIBUTIONS.md`.

## Pull Request Process
1. Fork the repository and create a feature branch.
2. Make your changes with clear, descriptive commits.
3. Open a PR with a detailed description of the change.
4. Maintainers will review and provide feedback.

## Code of Conduct
Be respectful, constructive, and collaborative. Security research is a team effort.
